# 薪邮 · 安装说明

适用版本 0.1.0 · macOS 13 及以上 · Apple 芯片与 Intel 通用（同一个包）

> 这份说明**跟着安装包一起发**（dmg 根目录里就有）。装之前先读「一」。

## 一、装之前先校验

在 dmg 所在的文件夹里打开「终端」，执行：

```bash
shasum -a 256 -c *.sha256
```

看到 `薪邮-0.1.0.dmg: OK` 就是文件完整，可以装。
看到 `FAILED` 就**先别装**，把结果发给发包的人。

## 二、安装

1. 双击 `薪邮-0.1.0.dmg`（文件名里的版本号以实际收到的为准）。
2. 把「薪邮」拖进「应用程序」文件夹。
3. 拖不动时：双击 dmg 里的「薪邮」图标 → 菜单栏「应用程序」→「发送到应用程序」。

## 三、第一次打开：几个弹窗，都是正常的

**弹窗 1：「无法打开，因为无法验证开发者」**

这个包没有苹果开发者签名（内部试用版没买证书），macOS 会拦一次。
绕过它，两种办法任选：

- 右键点「应用程序」里的「薪邮」→ 选「打开」→ 弹窗里再点「打开」；
- 或 打开「系统设置 → 隐私与安全性」→ 往下找到「薪邮」→ 点「仍要打开」。

终端里执行可确认原因：

```bash
spctl -a -vv /Applications/薪邮.app
```

会看到这两行：

```
/Applications/薪邮.app: rejected
source=no usable signature
```

意思是「没有可用签名」，**不是包坏了**（内部试用版没买证书）。

**弹窗 2：钥匙串授权**

应用要读写数据库密钥，macOS 会弹出（原文照抄）：

> “薪邮”想要访问你的钥匙串中的密钥“cn.payslipmailer.db-key”。
> 若要给予许可，请输入“登录”钥匙串的密码。

在这个框里输入**你 Mac 的登录密码**（不是管理员口令、也不是飞书密码），点**「允许」**。

> ⚠️ 点「拒绝」的后果：下次启动进不去主界面（提示找不到密钥），
> 只能重新初始化或用备份恢复。
>
> 每换版本这个弹窗都会再问一次 —— 没签名的程序每次编译身份都变了，属正常。

**提示 3：「在搭载 Apple 芯片的 Mac 上使用基于 Intel 的 App」**

只出现一次，是 macOS 对**未签名**应用的一次性提示。
这个包是通用二进制（Apple 芯片原生运行 + Intel 兼容），点「仍要打开」即可。

## 四、首启三步

1. **设管理员口令**：没有找回途径，忘了只能清空重来（工资记录会一起没）。
2. **填发信邮箱**：「设置 → 邮件配置」。主机 `smtp.feishu.cn`、端口 `465`、SSL，
   用户名填完整邮箱，密码填**专用密码**（不是登录密码）。
   点「测试连接」会发一封自检信给自己，收到即配置正确。
3. **配这个月**：字段 → 成员 → 模板 → 建账套 → 导空模板给财务填 → 导回来核对后发送。

## 五、卸载

把「应用程序」里的「薪邮」拖进废纸篓，就是卸载。

**数据不会跟着删**，它们留在这两处：

| 东西 | 位置 |
|---|---|
| 加密数据库与导出目录 | `~/Library/Application Support/cn.payslipmailer.desktop/` |
| 钥匙串条目 | `cn.payslipmailer.db-key`（删了应用就开不了库，要换机器时别删） |

工资记录按合规要求留存，**卸载 ≠ 删数据**。
要彻底清空：应用内「设置 → 清空数据」（连备份一起清掉，撤不回来）。

**换一台 Mac**：旧机「导出加密备份」（用口令加密）→ 新机装好后「恢复」。

## 六、出问题怎么办

| 现象 | 怎么办 |
|---|---|
| 双击没反应 / 提示无法验证开发者 | 没签名，见「三」的弹窗 1 |
| 又弹「想要访问钥匙串」 | 换版本了，点「允许」 |
| 找不到密钥 / 进不去主界面 | 点过「拒绝」或换了机器：重新初始化，或用备份恢复 |
| 提示「发信设置还没配置」 | 去 设置 → 邮件配置 |
| 发信报 535 | 专用密码失效：飞书桌面端重新生成 |
| 发信卡住 | 对方限流，等自动重试 |

校验值（`.sha256`）与本说明**随包提供**；发布记录由发包方留存，可索取。
与本文不符时以发布记录为准。
