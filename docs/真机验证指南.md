# 真机验证指南（TC-501 与遗留的真机项）

给使用者的一页操作单。这些项**必须在真机上由人完成** —— 不是流程拖沓，
而是它们验证的本来就是「真人 + 真硬件 + 真凭据」才能出的结果。

## 二、TC-501 · 发信真机验证（需要飞书专用密码）

### 1. 生成飞书专用密码（只在飞书**桌面客户端**，手机端/网页端不行）

前提：企业版飞书邮箱，且管理员已开启「第三方邮箱客户端登录」。

1. 打开飞书桌面客户端 → 左上角**头像** → **设置**
2. **邮箱** → **第三方邮箱客户端登录** → 选择设备 → **生成专用密码**
3. 复制那串密码（它只显示一次）

> 专用密码不是飞书登录密码。安全顾虑可以放心：它随时可以在同一页面**删除**
> —— 删除后该客户端立即断开，应用重新配一个就行。

### 2. 在应用里配置并测试

1. 应用 → **设置 → 邮件配置**
2. 填：SMTP 主机 `smtp.feishu.cn`、端口 `465`、加密 SSL、
   用户名 = 你的完整飞书邮箱、专用密码 = 刚才那串、
   发件人名称（如「人力资源部」）、发件地址 = 同邮箱、速率 30 封/分
3. **保存**（密码只进 macOS 钥匙串 —— 数据库里搜不到它）
4. 点**测试连接** → 你的收件箱应收到一封「薪邮 · 测试连接自检」

**收到自检信 = TC-501 的核心通过**。若报 535：专用密码不对或被删了，
重新生成再填。

### 3. 真发 5 封（完整链路）

1. 工资条项目 → 确认默认 7 项都在
2. 邮件组与成员 → 加 5 个**真实收得到的**地址（自己的几个邮箱/同事）
3. 月度工资表 → ＋ 新建月份 → 录几个数（或走导出/导入链路）
4. 标记为待发送 → 预览与核对 → 核对发送范围（全绿才放行）→ 发送 → 确认
5. 观察：逐封以 ~2 秒一封的节奏出去；发送历史里每封有回码与时间

**验证点**：每人只收到**自己**的工资条；没有人收到两封（除非恢复过存疑任务）；
发送历史可导出 CSV 凭证且搜不到金额。
